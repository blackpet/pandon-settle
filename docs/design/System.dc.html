시그니처 · 영수증

이 앱이 기억에 남는 한 가지. 입력 화면의 미리보기와 정산 화면의 송금 목록이 같은 물건이다 — 절취선 위는 무슨 판이었는지, 아래는 얼마인지. 칩을 누를 때마다 아래쪽 숫자만 바뀌므로 시선이 확인 버튼을 떠나지 않는다. 나머지 화면은 조용하게 두고 개성은 여기에만 쓴다.
